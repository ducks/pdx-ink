# Directory design research

Reviewed the live Listeo and Listify directory demonstrations on September 11,
2026, before choosing the revised layout.

| Reference | Observed pattern | Application here |
| --- | --- | --- |
| [Listeo listings](https://listeo.pro/listings/) | Scannable cards with clear names, location, categories, and list/map browsing | A desktop filter sidebar, result count, two-column cards, neighborhood row, specialization chips, and the plugin's existing list/map views |
| [Listify Classic](https://listify-demos.astoundify.com/classic/) | A prominent search entry point and concise directory introduction | A compact city banner followed directly by search and filters; controls stack above results on mobile |
| [Tattooing 101: neo-traditional](https://tattooing101.com/learn/styles/neo-traditional-tattoos/) and [Tattoodo: neo-traditional](https://www.tattoodo.com/guides/styles/neo-traditional) | Defined outlines, decorative detail, and an expanded earthy palette | Forest green, oxblood, ochre, and cream, outlined cards, and an original four-point ornament |

The production snapshot has five tattooers and one shop, with no profile images.
Large first-and-last initials provide a consistent visual anchor. Alternating
panel colors are decorative and communicate no ranking or artist classification.
Actual photos, when supplied through the existing plugin, replace the initials.

Barlow Condensed gives headings a bold sign-painting character without serifs;
Barlow keeps descriptions and controls readable. Both are bundled, openly
licensed fonts. The community uses the same type, surfaces, borders, and accent
colors while retaining native Discourse topic and composer controls.

**PDX Flash** is the cream light palette. **PDX After Hours** uses dark green
surfaces, cream text, sage, and coral accents. The palettes use Discourse's native
color-mode system. Editorial links on Latest are explicitly labeled and editable
in the separate PDX Editorial component.

No third-party theme code or imagery was copied. Ratings, booking status,
promotions, and paid listing features from the reference themes were not added.
